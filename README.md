# 🔍 QR Decoder - Online Web Tool

A lightweight, fast, and secure **QR Code Decoder** built with JavaScript. This tool allows users to scan and read QR codes directly from their browser using a webcam or by uploading an image file.

🚀 **Live Demo:** [https://gpldroid.github.io/qr-decoder/](https://gpldroid.github.io/qr-decoder/)

---

## ✨ Features
* **Camera Scan:** Real-time QR code scanning using your device's camera.
* **Image Upload:** Decode QR codes from local images (PNG, JPG, etc.).
* **Privacy Focused:** All decoding happens locally in your browser. No data is sent to any server.
* **Responsive Design:** Works perfectly on desktops, tablets, and smartphones.
* **Zero Dependencies:** Lightweight and fast loading.

## 🛠️ Built With
* **HTML5 & CSS3:** For the structure and styling.
* **JavaScript (Vanilla):** For the logic and interaction.
* **QR Scanner Library:** (If you are using one like `jsQR` or `html5-qrcode`, mention it here).

## 🚀 How to Use
1.  **Open the link:** Go to the [Live Demo](https://gpldroid.github.io/qr-decoder/).
2.  **Choose Mode:**
    * Click **"Scan with Camera"** to use your webcam.
    * Click **"Upload Image"** to select a screenshot or a saved QR code image.
3.  **Get Result:** The decoded text or URL will appear instantly on the screen.
